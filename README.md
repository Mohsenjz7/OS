# درس‌نامهٔ فارسی زمان‌بندی CPU

سایت تک‌صفحه‌ای فارسی (RTL) برای مرور فصل پنجم زمان‌بندی CPU، با **تصاویر منتخب واقعی از PDF اسلایدهای درس**.

## امکانات

- فهرست درختی و کشویی بخش‌ها و زیربخش‌ها در سمت راست
- جستجو در متن و نمایش مناسب در موبایل
- حالت روشن و تاریک
- جدول‌ها، فرمول‌ها و مثال‌های آموزشی
- تصاویر اسلایدهای اصلی در کنار توضیحات مرتبط، با قابلیت باز کردن در اندازهٔ بزرگ
- بخش «مرور سریع و خودآزمایی» با ۱۴ زیربخش، فرمول‌های کلیدی، جدول‌های مقایسه و ۵ سؤال تعاملی

## فایل‌ها

- `index.html`: صفحهٔ اصلی سایت
- `assets/slides/*.webp`: تصاویر منتخب اسلایدهای ارائه‌شده توسط کاربر
- `.nojekyll`: جلوگیری از پردازش غیرضروری Jekyll در GitHub Pages

## انتشار در GitHub Pages

1. فایل ZIP را استخراج کنید.
2. **محتویات** فولدر را (نه خود فایل ZIP و نه یک پوشهٔ اضافی) در ریشهٔ مخزن GitHub قرار دهید.
3. در `Settings → Pages` گزینهٔ `Deploy from a branch` را انتخاب کنید.
4. شاخهٔ `main` و مسیر `/(root)` را انتخاب کرده و `Save` بزنید.
5. اگر مخزن `OS` و نام حساب `Mohsenjz7` باشد، نشانی نمونهٔ سایت: `https://mohsenjz7.github.io/OS/`

## به‌روزرسانی با Git

```bash
git add .
git commit -m "Add lecture slide images"
git pull --rebase origin main
git push origin main
```

اگر `pull` تداخل داشت، ابتدا تداخل را حل کنید. از `git push --force` بدون بررسی استفاده نکنید.

## منبع تصاویر

تصاویر از PDF اصلی `ch5-cpu-scheduling(1).pdf`، درس Lecture 5: CPU Scheduling، Hossein Asadi، پاییز ۲۰۲۶ استخراج شده‌اند. شمارهٔ هر اسلاید در زیر تصویر مشخص است. تصاویر باید با رعایت حقوق منبع منتشر شوند.

برای نمایش MathJax و فونت آنلاین در بارگذاری اولیه اینترنت لازم است؛ تصاویر اسلایدها در خود پروژه قرار دارند.
